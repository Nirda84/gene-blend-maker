# הוספת תצוגת תמונה במסך מלא (Lightbox)

## מה הבעיה
בעמוד `/create`, כשמגיעים לתוצאה הסופית (וגם בגלריית ההיסטוריה), אי אפשר ללחוץ על התמונה כדי להגדיל אותה. המשתמש לא יכול לראות את הפרטים בתמונה היטב.

## הפתרון
שימוש ברכיב `Dialog` הקיים בפרויקט (`src/components/ui/dialog.tsx`, מבוסס Radix) כדי לפתוח לייטבוקס שמציג את התמונה בגודל מלא על המסך.

## מה ייבנה

### 1. רכיב חדש: `ImageLightbox`
קובץ חדש: `src/components/genblend/ImageLightbox.tsx`
- מקבל `src`, `alt`, `open`, `onOpenChange`
- משתמש ב-`Dialog` מ-shadcn עם `DialogContent` מותאם:
  - רוחב מקסימלי כמעט מלא (`max-w-[95vw]` / `max-h-[95vh]`)
  - בלי padding פנימי, רקע שקוף
  - תמונה ב-`object-contain` כדי לשמור פרופורציות
  - כפתור הורדה קטן בפינה
- סגירה אוטומטית בלחיצה על overlay (התנהגות ברירת מחדל של Radix Dialog ✓) וגם ב-X וב-Esc

### 2. שילוב בעמוד `src/routes/create.tsx`
- הוספת state: `lightboxImage: { url: string; alt: string } | null`
- **תוצאה ראשית (שורות ~621-627):** עטיפת ה-`<img>` ב-`<button>` עם `cursor-zoom-in`, onClick פותח את הלייטבוקס. הוספת רמז ויזואלי קטן (אייקון זכוכית מגדלת בפינה שמופיע ב-hover).
- **גלריית היסטוריה (שורות ~707-726):** ה-`<button>` הקיים כרגע קורא ל-`handleSelectFromHistory`. נשנה את ההתנהגות: לחיצה על התמונה פותחת לייטבוקס. נוסיף כפתור קטן נפרד ("בחר") אם רוצים לטעון אותה כתוצאה הראשית — או נשאיר את `handleSelectFromHistory` רק עבור הכרטיס ההיסטוריה כברירת מחדל ובלייטבוקס יהיה כפתור "השתמש כתוצאה ראשית". **החלטה: לחיצה על התמונה = פתיחת לייטבוקס. בתוך הלייטבוקס יהיה גם כפתור הורדה.**
- רינדור של `<ImageLightbox>` ברמת העמוד.

## מה לא משתנה
- שום לוגיקה עסקית (יצירה, היסטוריה, אנליטיקה).
- כל שאר הכפתורים (Download, Share, Copy link, Regenerate) נשארים כפי שהם.
- העיצוב הקיים של כרטיס התוצאה והגלריה נשמר — רק הוספת אינטראקציה.

## פרטים טכניים
- שימוש ב-`ZoomIn` icon מ-`lucide-react`.
- ה-Dialog של shadcn כבר תומך בסגירה ב-overlay click וב-Esc — אין צורך ב-config נוסף.
- אין שינוי בטיפוסים, ב-DB, או ב-server functions.
